# AgentCore Memory Notebooks
This repo contains new or adapted  Jupyter notebooks customized for use with an AWS-led "Diving Deep into Bedrock AgentCore" workshop session on long-term Memory. 

### Disclaimer
This is not part of the officially published workshops from AWS. This is a workaround to provide workshops participants with an optimal experience with select notebooks while the official workshop is being updated. The code in this repo may become outdated and may not work (or be needed) as new workshop releases are published.

## Prerequisites
* Attend an AWS-led "Diving Deep into Bedrock AgentCore" hands-on workshop
